# MTG Booster Monitor

Веб-приложение для сравнения бустеров Magic: The Gathering. Показывает показатели европейского рынка, позволяет закреплять бустеры, группировать их по папкам и сравнивать стоимость содержимого с ценой в конкретном магазине.

## Возможности

- Поиск по выпуску и типу бустера, закрепления и папки с сортировкой показателей.
- Средняя и медианная стоимость содержимого, ожидаемый возврат и шансы дорогих карт по данным TCG Balance.
- Пересчёт цены магазина в евро. Автоматические курсы предоставляет ЕЦБ, курс RUB поступает из Банка России.
- Оценка вероятности окупить бустер по заданной цене. Для выбранного продукта можно построить модель по весам карт MTGJSON и ценам Scryfall.

## Запуск

Требуется Docker с плагином Compose. Выполните команды из корня репозитория:

```bash
docker compose up -d --build
docker compose exec -T app python -m sync
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765). Чтобы сравнить бустеры, откройте **Каталог**, закрепите нужные позиции и добавьте их в папку. Цену магазина и валюту можно указать при добавлении или позднее в карточке бустера.

Compose хранит SQLite в именованном томе `data`. Курс валют обновляется при старте и каждые шесть часов. Каталог и показатели отслеживаемых бустеров обновляются командой `python -m sync`. Для ежедневной синхронизации на Linux эту команду можно запускать по расписанию через cron.

Контейнер публикует порт через loopback. Для доступа с другого компьютера используйте SSH-туннель или HTTPS-прокси с аутентификацией перед приложением.

## Архитектура

| Файл | Назначение |
|---|---|
| `app.py`, `templates/`, `static/` | Интерфейс на FastAPI и Jinja2 |
| `sources.py`, `sync.py` | Загрузка и проверка каталога, метрик и валютных курсов |
| `storage.py` | Хранение папок, цен и снимков показателей в SQLite |
| `model.py` | Расчёт распределения стоимости содержимого бустера и вероятностей отдельных карт |
| `tests/` | Проверки разбора данных, модели и пользовательского сценария |

Если обновление источника завершается ошибкой, приложение использует последний успешно загруженный снимок. Цена магазина и исходная валюта хранятся отдельно от результата конвертации.

## Шанс окупить пак и шансы отдельных карт

Для этих показателей нужно построить модель каждого интересующего бустера. Сборщик TCG Balance загружает опубликованные сводные метрики независимо от модели. При наличии модели приложение считает шанс окупаемости и для цены рынка, и для твоей цены. Конвертация используется до округления суммы на экране.

Пример для **Outlaws of Thunder Junction Play Booster**. Команды для Bash выполняются из папки проекта. Загрузки могут занять несколько минут.

```bash
mkdir -p input
for set_code in OTJ BIG OTP SPG; do
  curl -fL "https://mtgjson.com/api/v5/${set_code}.json" -o "input/${set_code}.json" || break
done
curl -fsSL -A 'PersonalBoosterMonitor/1.0' \
  https://api.scryfall.com/bulk-data/default-cards -o input/scryfall-meta.json
```

Из ответа Scryfall можно получить URL файла `jsonl_download_uri`. Следующий блок использует Python из контейнера, а цену скачивает прямо в `input` на VPS.

```bash
price_url=$(docker compose exec -T app python -c "import json,sys; print(json.load(sys.stdin)['jsonl_download_uri'])" < input/scryfall-meta.json)
curl -fL "$price_url" -o input/default-cards.jsonl.gz
```

Построй модель. Для чтения входных файлов Compose запускает одноразовый контейнер с той же базой и подключает папку `input` в режиме чтения. Файлы должны быть доступны пользователю контейнера на чтение.

```bash
docker compose run --rm --no-deps -v "$PWD/input:/input:ro" app \
  python -m model /sets/outlaws-of-thunder-junction/play \
  /input/OTJ.json /input/default-cards.jsonl.gz \
  --extra-set /input/BIG.json --extra-set /input/OTP.json --extra-set /input/SPG.json
```

Обнови карточку. В ней появятся модельные шансы окупаемости по обеим ценам при наличии самих цен, а также список версий карт с фильтром по названию.

Для **Murders at Karlov Manor Collector Booster** скачай `MKM.json` и `MKC.json` по той же схеме. Затем выполни:

```bash
docker compose run --rm --no-deps -v "$PWD/input:/input:ro" app \
  python -m model /sets/murders-at-karlov-manor/collector \
  /input/MKM.json /input/default-cards.jsonl.gz \
  --extra-set /input/MKC.json --extra-set /input/SPG.json
```

Для другого продукта укажи его путь, JSON основного выпуска и JSON связанных выпусков через повторяемый параметр `--extra-set`. Если тип на TCG Balance и ключ в MTGJSON различаются, передай `--model-key` с проверенным ключом. При неизвестном ключе программа перечислит доступные конфигурации. Старые выгрузки Scryfall в виде JSON-массива тоже поддерживаются. Обновление цены рынка происходит при синхронизации, а распределение стоимости и цены отдельных карт обновляются при повторном запуске `model` со свежими файлами.

Модель берёт веса конфигураций и листов из [MTGJSON](https://mtgjson.com/data-models/booster/booster-config/), склеивает выпуски по UUID карты и сопоставляет цены через Scryfall ID, отдельно для обычных и фойловых версий. Проводится 100 000 воспроизводимых симуляций с независимыми выборами внутри заданной конфигурации. Шанс окупить равен доле симуляций, в которых сумма цен карт достигла цены покупки. Шанс конкретной карты считается аналитически в той же модели. Печатные корреляции и ограничения на повторные карты в паке не моделируются. Неразрешённый UUID останавливает расчёт. Если UUID известен, но цены EUR нет, вклад карты в стоимость симулированного пака равен нулю. В карточке показываются дата расчёта и покрытие. Оценки модели могут отличаться от показателей TCG Balance.

## Тесты

При установленном Python 3.12 или новее:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

## Источники данных

- [TCG Balance](https://tcgbalance.com/how-it-works) — метрики рынка EU и методика их расчёта.
- [MTGJSON](https://mtgjson.com/) и [Scryfall](https://scryfall.com/) — параметры бустеров и цены карт для модели.
- [ЕЦБ](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html) и [Банк России](https://www.cbr.ru/currency_base/daily/) — справочные курсы валют.

Стоимость карт оценивается по рыночным ценам. Комиссии, доставка и фактическая выручка от продажи в расчёт не входят.
